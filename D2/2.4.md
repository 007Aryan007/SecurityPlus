# CompTIA Security+ (SY0-701)
## Section 2.4 - Malicious Activity

### 1. Malware
*   **Trojans & RATs:** Malware disguised as legitimate software. Relies on social engineering (tricking the user) to install. A **Remote Access Trojan (RAT)** creates a backdoor for administrative control.
*   **Worms:** Self-replicating malware that spreads across a network automatically by exploiting vulnerabilities. **Exam Trick:** Viruses need human interaction/host files; Worms do not. They cause DoS by consuming bandwidth.
*   **Spyware & Keyloggers:**
    *   **Spyware:** Secretly monitors activity (cookies, browsing).
    *   **Software Keylogger:** Malware that records keystrokes. Defeated by Antivirus/EDR.
    *   **Hardware Keylogger:** A physical USB device intercepting keystrokes before the OS sees them. Cannot be detected by Antivirus. Requires physical security inspections.
*   **Rootkits:** Malware with system-level/kernel privileges designed to hide itself and other malware from the OS and Antivirus. 
    *   *Defense:* **UEFI Secure Boot** prevents boot-level rootkits. Usually requires a complete system reimage to eradicate.
*   **Fileless Malware:** Operates entirely in memory (RAM). Never drops a traditional executable (like `.exe`) on the hard drive. Hijacks trusted system tools like **PowerShell** to execute scripts. 
    *   *Defense:* Endpoint Detection and Response (EDR) for behavioral monitoring.

### 2. Network & Resource Attacks
*   **DoS vs. DDoS:** 
    *   **DoS:** One attacker vs. one target.
    *   **DDoS:** A botnet (thousands of devices) vs. one target.
    *   **Reflection & Amplification:** Spoofing the victim's IP and sending small requests to legitimate servers (like DNS), which "reflect" massive, amplified responses back to the victim, flooding their network.
*   **ARP Poisoning:** Strictly a **Local Area Network (LAN)** attack. The attacker sends fake MAC-to-IP translations to force local traffic through their machine. Used to set up local On-Path attacks.
*   **DNS Hijacking & Spoofing:** Altering the internet's "phonebook" to redirect a legitimate URL (like www.bank.com) to a fake IP address. Can happen globally. 
    *   *Defense:* **DNSSEC** (adds digital signatures to DNS records).
*   **On-Path (MitM) Attacks:** Secretly intercepting communications between two parties to steal (eavesdropping) or alter (manipulation) data. Defeated by end-to-end encryption.
*   **Wireless Attacks:**
    *   **Rogue AP:** An unauthorized (often cheap/unsecured) router plugged into the corporate network, usually by an ignorant employee. Creates a backdoor.
    *   **Evil Twin:** A malicious hotspot set up by a hacker broadcasting the same name (SSID) as a legitimate network to intercept traffic.
*   **802.1X (Port-Based Network Access Control):** The "Bouncer" for wall jacks and Wi-Fi. Requires digital certificates/credentials before allowing network access. Stops Rogue APs dead in their tracks. Uses a Supplicant (device), Authenticator (switch), and Authentication Server (RADIUS).

### 3. Credential Attacks
*   **Brute-Force:** Trying every mathematical combination of characters. 
    *   *Online:* Attacking a live login page (Slow, stopped by Account Lockouts).
    *   *Offline:* Attacking a stolen database file on the hacker's own hardware (Extremely fast, lockouts don't work).
*   **Dictionary Attack:** Trying a list of known words, phrases, and leaked passwords. Faster than brute-force.
*   **NTDS.dit:** The master Active Directory database file on a Domain Controller. Holds all user password hashes. The ultimate target for an offline credential attack.
*   **Rainbow Tables:** A massive, pre-computed database of password hashes. Turns cracking into a fast search query.
    *   *Defense:* **Salting** (adding random data to a password before hashing it). Salting breaks rainbow tables.
*   **Password Spraying:** A "horizontal" attack. Trying 1 or 2 common passwords against *thousands* of accounts to avoid triggering Account Lockout policies.
*   **Credential Stuffing:** Taking username/password combinations leaked from a breach on one website and automatically plugging them into other high-value websites, relying on human password reuse. 
    *   *Defense:* **Multi-Factor Authentication (MFA)**.
