# CompTIA Security+ Notes: 4.3 Monitoring, Alerting & Defense Tooling

This section covers the specialized software and hardware systems used by security teams to detect malicious activity, analyze logs, and actively block network and application-level attacks.

## 1. Monitoring & Alerting (SIEM)

A **SIEM (Security Information and Event Management)** system is the central nervous system of a Security Operations Center (SOC). It collects and analyzes security data from across the entire enterprise.

### Log Aggregation

* **Concept:** Network devices, servers, and applications generate millions of log entries daily. A SIEM collects (aggregates) all these dispersed logs into a single, centralized database.
* **Benefit:** Analysts do not have to log into 50 different firewalls and servers to piece together an attack; all the data is in one place. Logs are often stored in WORM (Write Once, Read Many) format to prevent tampering.

### Correlation

* **Concept:** The analytical "brain" of the SIEM. Correlation links seemingly unrelated events from different sources to identify a larger attack pattern.
* **Example:** 
  1. Firewall logs an inbound connection from a foreign IP. 
  2. Active Directory logs 5 failed login attempts followed by a success. 
  3. A database logs a massive data export.
  *Individually, these might be ignored. Correlated together, the SIEM recognizes a successful brute-force attack and data exfiltration.*

### Alerting Rules

* **Concept:** Predefined conditions or thresholds programmed into the SIEM. 
* **Function:** When correlation engines detect a pattern matching an alerting rule (e.g., "Alert if a user fails login 10 times in 1 minute, then succeeds"), the SIEM generates an alert/ticket for a security analyst to investigate.

## 2. Defense Tooling

These are the active and passive tools deployed across the network and endpoints to thwart attackers.

### Next-Generation Firewalls (NGFW)

* **Traditional Firewalls:** Only filter traffic based on IP addresses and Port numbers (OSI Layers 3 & 4).
* **NGFW:** Performs Deep Packet Inspection (DPI) and operates up to the Application Layer (OSI Layer 7). 
* **Capabilities:** Can identify specific applications (e.g., allowing Facebook but blocking Facebook Games), integrate Intrusion Prevention Systems (IPS), and filter traffic based on user identity (Active Directory integration).

### IDS/IPS (Intrusion Detection and Prevention)

* **IDS (Intrusion Detection System):** *Passive*. Monitors network traffic and sends an alert if malicious activity is detected. It is deployed out-of-band (on a span port) and does not stop the attack.
* **IPS (Intrusion Prevention System):** *Active*. Sits in-line with the traffic. If it detects malicious activity, it drops the packets and blocks the attack in real-time.
* **Detection Methods:**
  * **Signature-based:** Compares traffic against a database of known threats/malware signatures. Fast, but cannot stop unknown/zero-day attacks.
  * **Heuristic/Behavioral/Anomaly-based:** Establishes a baseline of "normal" network traffic. If traffic deviates significantly from the baseline, it flags it. Better at catching zero-day attacks but has a higher false-positive rate.

### Web Application Firewalls (WAF)

* **Function:** Specifically designed to protect web servers and web applications. It operates purely at Layer 7 (HTTP/HTTPS traffic).
* **Use Case:** Protects against web-specific attacks that a standard network firewall would miss, such as the OWASP Top 10 (SQL Injections, Cross-Site Scripting (XSS), directory traversals).

### Network Access Control (NAC)

* **Function:** Acts as a security bouncer for the network. It checks the "health" or "posture" of a device *before* allowing it to connect.
* **Mechanism:** When a laptop plugs into the wall (using 802.1X authentication), the NAC checks: Is the OS fully patched? Is the Antivirus updated? Is the host firewall on?
* **Result:** If the device passes, it joins the production network. If it fails, it is placed in a restricted "Quarantine" or "Remediation" VLAN until the issues are fixed.

### EDR and XDR

* **EDR (Endpoint Detection and Response):** Advanced endpoint protection that continuously monitors device behavior (processes, registry changes) to detect and isolate ransomware and advanced persistent threats (APTs).
* **XDR (Extended Detection and Response):** Takes the concept of EDR and expands it. XDR correlates data not just from endpoints, but also from the network, cloud environments, and email gateways to provide a holistic, unified view of threats.

### DLP (Data Loss Prevention)

* **Function:** Solutions designed to detect sensitive data (PII, PCI, PHI) and block it from leaving the corporate environment. (e.g., Blocking a user from uploading a customer database spreadsheet to their personal Dropbox).
