# CompTIA Security+ Notes: 4.1 Securing Computing Resources

This section focuses on hardening individual devices (endpoints) and standardizing configurations to reduce the attack surface and protect against malicious activity.

## 1. Endpoint Protection and Firewalls

Endpoints (laptops, desktops, servers, mobile devices) are often the first target of an attacker.

### Endpoint Protection
* **Antivirus (AV) / Anti-malware:** Software designed to detect and remove malicious software, traditionally using signature-based detection (comparing files against a known list of malware).
* **EDR (Endpoint Detection and Response):** A modern, behavioral-based solution that continuously monitors endpoint activity. It looks for suspicious actions rather than just known malware signatures, allowing it to stop zero-day threats and isolate compromised machines automatically.

### Host-Based Firewalls
* **Definition:** A software firewall installed directly on an individual computer (e.g., Windows Defender Firewall, iptables for Linux).
* **Function:** Monitors and controls incoming and outgoing network traffic for that specific machine based on predetermined security rules.
* **Network vs. Host:** A network firewall protects the entire network perimeter, while a host-based firewall adds a layer of defense-in-depth in case an attacker bypasses the perimeter or originates from inside the network (lateral movement).

## 2. Hardening and Configuration Management

System hardening involves securing a system by reducing its vulnerabilities, primarily through configuration management.

### Secure Baselines
* **Definition:** A documented set of standardized security configurations (a "gold standard") applied to operating systems or applications. 
* **Purpose:** Ensures every new system deployed meets minimum security requirements. Organizations often use industry-standard baselines, such as those provided by the CIS (Center for Internet Security).

### Port and Service Disabling
* **Principle of Least Functionality:** A system should only be configured with the capabilities, ports, and services absolutely necessary to do its job.
* **Action:** If a web server does not need FTP (Port 21), disable the FTP service and block the port. Leaving unnecessary ports open or running unused services creates needless entry points for attackers.

### Application Allow Lists and Deny Lists
These mechanisms control exactly what software is permitted to run on an endpoint.

* **Allow List (formerly Whitelist):** Implicit deny. Only explicitly approved applications are allowed to execute; everything else is blocked by default. This is highly secure but requires significant administrative overhead to maintain.
* **Deny List (formerly Blacklist):** Implicit allow. All applications are allowed to execute except those specifically placed on the blocked list. Less secure, as new or unknown malware will bypass the block list.

## 3. Sandboxing

* **Definition:** An isolated, controlled testing environment (often a virtual machine) where unverified programs, untrusted code, or suspicious attachments can be executed safely.
* **Purpose:** If the software acts maliciously (e.g., a malware sample attempts to encrypt files or connect to a command-and-control server), it only affects the sandbox. The host operating system and the rest of the network remain completely safe. 

## 4. Mobile Device Management (MDM)

MDM involves the centralized administration of mobile devices (smartphones, tablets, laptops) to secure corporate data, especially in BYOD (Bring Your Own Device) environments.

* **Key MDM Capabilities:**
  * **Device Policies:** Enforcing mandatory screen locks, complex PINs, and timeout restrictions.
  * **Full Device Encryption (FDE):** Requiring devices to encrypt all data at rest so it cannot be extracted if the device is lost or stolen.
  * **Remote Wipe:** The ability for an administrator to remotely erase all corporate data from a device if it is reported stolen or a user leaves the company.
  * **Containerization:** Creating a secure, encrypted, isolated "workspace" on a user's personal device. This keeps corporate apps and data completely separate from the user's personal apps and data, protecting privacy while securing company assets.
