# CompTIA Security+ (SY0-701) Practice Exam

## Domain 2.0: Threats, Vulnerabilities, and Mitigations

### Objective 2.4: Given a scenario, analyze malicious activity and attacks

### Section 1: Performance-Based Questions (PBQs)

#### PBQ 1: Malware Behavior and Threat Identification Matrix

**Scenario:**
As a Tier 2 SOC Analyst, you are reviewing a series of escalated endpoint alerts. You need to classify the specific type of malware based on its observed behavior on the compromised systems. 

**Task:**
Match the **Behavioral Observation** to the correct **Malware Type**.

**Malware Types:**
* Ransomware
* Trojan
* Worm
* Spyware / Keylogger
* Rootkit
* Fileless Malware

**Observations:**

| Alert ID | Behavioral Observation | Malware Type | 
| ----- | ----- | ----- | 
| **Alert 101** | A user downloaded what appeared to be a legitimate free PDF editor. Upon installation, a backdoor was silently opened on port 4444, allowing remote access to the attacker. |  | 
| **Alert 102** | Without any user interaction, malicious code exploited an SMB vulnerability on a file server, replicated itself, and actively scanned the subnet to infect 45 other vulnerable servers in under five minutes. |  | 
| **Alert 103** | An antivirus scan shows a clean system, but the host operating system is acting erratically. A forensic memory dump reveals malicious hooks injected deeply at the OS kernel level, actively hiding specific active processes and files from being displayed in Task Manager. |  | 
| **Alert 104** | An attacker clicked a malicious link, but no `.exe` was written to the hard drive. Instead, the payload executed entirely in RAM by hijacking native Windows tools like PowerShell and WMI to carry out its objectives (Living off the Land). |  | 
| **Alert 105** | All documents, images, and database files on a workstation have had their extensions changed to `.enc`. A `.txt` file on the desktop contains instructions to pay 0.5 Bitcoin to a specific wallet address to receive the decryption key. |  | 

#### PBQ 2: Attack Vector Log Analysis

**Scenario:**
You are analyzing security logs and physical security reports from the past week. 

**Task:**
Identify the specific **Attack Type** being executed in each scenario. 

**Attack Types:**
* ARP Poisoning
* DNS Spoofing / Hijacking
* Distributed Denial of Service (DDoS) - Amplification
* Evil Twin
* Rogue Access Point
* Credential Stuffing
* Password Spraying

**Log / Incident Reports:**

| Incident Report | Observed Activity | Attack Type | 
| ----- | ----- | ----- | 
| **Incident A** | Web server logs indicate that millions of login attempts occurred overnight. The attacker used thousands of unique usernames but tried only three common passwords (`Summer2024!`, `Welcome1!`, `Password123`) against each account to avoid triggering account lockouts. |  | 
| **Incident B** | A user in a coffee shop attempted to connect to the shop's Wi-Fi network `CoffeeFreeNet`. The user accidentally connected to an attacker's laptop broadcasting a network with the exact same SSID and MAC address, allowing the attacker to perform a Man-in-the-Middle (MitM) attack. |  | 
| **Incident C** | An attacker acquired a database of usernames and passwords breached from a popular fitness app. The attacker then used an automated script to inject these exact username/password combinations into a corporate banking portal, successfully compromising users who reused their passwords. |  | 
| **Incident D** | On the local corporate LAN, an attacker's machine is sending unsolicited reply packets mapping the default gateway's IP address to the attacker's own MAC address. All traffic meant for the internet is now flowing through the attacker's machine. |  | 
| **Incident E** | An attacker sends thousands of tiny request packets to public Network Time Protocol (NTP) servers, spoofing the source IP address so it appears the requests came from the target company's web server. The NTP servers send massive response packets to the company's web server, overwhelming its bandwidth. |  | 

### Section 2: Scenario-Based Multiple-Choice Questions (MCQs)

#### Question 1
An attacker sits outside a corporate office building and plugs a small, unauthorized wireless router into an exposed Ethernet jack in the lobby. The router is broadcasting the SSID `Free_Internet` and allows the attacker a backdoor into the corporate LAN. Which of the following best describes this attack?
* A. Evil Twin
* B. Rogue Access Point
* C. On-path (MitM) attack
* D. DNS Hijacking

#### Question 2
A threat actor intercepts traffic between a user and an e-commerce website. The attacker alters the communication in real-time, downgrading the encryption and capturing sensitive session cookies without either party realizing the connection has been compromised. Which attack is occurring?
* A. On-path (Man-in-the-Middle) attack
* B. Brute-force attack
* C. Credential stuffing
* D. Rainbow table attack

#### Question 3
An attacker is attempting to crack a database of stolen password hashes. To speed up the process significantly, the attacker uses a massive, precomputed database of plaintext passwords and their corresponding hash values. What type of credential attack is this?
* A. Dictionary attack
* B. Rainbow table attack
* C. Password spraying
* D. Brute-force attack

#### Question 4
A user types `www.mybank.com` into their browser, but the local host file has been maliciously altered. The browser resolves the URL to an attacker-controlled IP address, displaying a fake login page that looks identical to the real bank. What type of attack has taken place?
* A. ARP poisoning
* B. Distributed Denial of Service (DDoS) reflection
* C. DNS hijacking / spoofing
* D. Keylogging

#### Question 5
A security analyst observes an executable hidden within a legitimate spreadsheet macro. When the spreadsheet is opened, it secretly tracks and records every keystroke the user makes, including passwords and emails, and sends them out to a remote command-and-control server. Which type of malware is this?
* A. Ransomware
* B. Spyware / Keylogger
* C. Fileless malware
* D. Worm

#### Question 6
An adversary wants to gain access to an organization's remote VPN. Because the organization locks accounts after five failed login attempts, the adversary decides to try a single password (`CompanyName2024!`) across 5,000 different employee usernames. What specific type of attack is this?
* A. Dictionary attack
* B. Password spraying
* C. Credential stuffing
* D. Rainbow table attack

#### Question 7
Which of the following attack methods specifically leverages the vulnerabilities of the Address Resolution Protocol (ARP) by manipulating the Layer 2 mapping of IP addresses to MAC addresses on a local subnet?
* A. ARP Poisoning
* B. DDoS Amplification
* C. Evil Twin
* D. DNS Spoofing

#### Question 8
Traditional antivirus software relies on scanning files on the hard drive for known malicious signatures. Which type of malware specifically attempts to evade this detection by executing directly in system memory (RAM) and exploiting legitimate administrative tools that are already installed on the OS?
* A. Fileless malware
* B. Trojan
* C. Ransomware
* D. Boot sector virus
