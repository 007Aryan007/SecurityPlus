#### PBQ 1: Breach Reconstruction & Threat Vector Classification

**Scenario:**
As a senior incident responder, you are reviewing five separate breach notifications submitted across your organization's global subsidiaries. Your task is to classify each incident by identifying the **Initial Threat Vector**, the **Primary Attack Surface Exploited**, and the most effective **Preventive Mitigation**.

**Incident Summaries:**

1. **Incident A:** A finance manager received a text message appearing to originate from the company's corporate travel provider stating: *"Flight cancelled—rebook immediately via bit.ly/corp-rebook-09."* The link directed the mobile browser to a spoofed Single Sign-On (SSO) login page that captured the manager's credentials and session cookie.
2. **Incident B:** A third-party HVAC maintenance technician connected a vendor-supplied USB diagnostic thumb drive into an air-gapped industrial control workstation to update sensor firmware. Unknown to the technician, the USB drive had been infected at the vendor's warehouse with wormable malware that immediately began enumerating local PLC network segments.
3. **Incident C:** An attacker compromised an open-source JavaScript formatting library hosted on a public package registry. When the enterprise's automated CI/CD pipeline pulled the latest dependency version during a nightly build, malicious post-install scripts executed inside the build container and exfiltrated production cloud deployment keys.
4. **Incident D:** An IT help desk analyst received a phone call from an individual using real-time voice-cloning software to impersonate the Vice President of Sales. Claiming to be boarding an international flight with a broken phone, the caller pressured the analyst into generating a temporary multi-factor authentication (MFA) bypass code.
5. **Incident E:** While working from a hotel lobby, a regional director connected a corporate laptop to an open Wi-Fi network named `Hotel_Guest_Free_5G`. The access point was actually operated by an attacker in the parking lot who intercepted unencrypted DNS queries and redirected internal intranet requests to a credential-harvesting portal.

**Selection Pools:**

* **Initial Threat Vectors:**
  * Vishing (Voice Phishing)
  * Smishing (SMS Phishing)
  * Supply Chain Compromise
  * Removable Media
  * Unsecure Wireless Network
  * Spear Phishing (Email)

* **Primary Attack Surfaces Exploited:**
  * Human / Social Engineering Surface
  * Physical / Air-Gapped Endpoint Surface
  * Software Build / Dependency Surface
  * Wireless / Remote Network Surface

* **Preventive Mitigations:**
  * Enforce Always-On VPN with certificate-based mutual authentication and disable auto-connect to open SSIDs.
  * Mandate out-of-band identity verification via an established callback directory before resetting MFA or credentials.
  * Implement Endpoint Device Control policies to block unauthorized mass storage mounting and require kiosk malware scanning.
  * Pin dependency versions, verify cryptographic package signatures, and utilize a private vetted artifact repository.
  * Deploy mobile threat defense (MTD) link filtering and enforce FIDO2/WebAuthn phishing-resistant hardware tokens.

#### PBQ 2: Attack Surface Audit & Exposure Remediation

**Scenario:**
An enterprise is conducting an Attack Surface Management (ASM) review following a rapid migration to a hybrid cloud architecture. Review the four vulnerability scan findings below and answer the architectural questions that follow.

```
                  [ Public Internet ]
                           │
     ┌─────────────────────┼─────────────────────┐
     ▼                     ▼                     ▼
[Finding 1]           [Finding 2]           [Finding 3]
Legacy IPSec VPN      Mobile App REST       AWS S3 Bucket &
Appliance (Port 500)  Gateway (/api/v1/*)   IAM Role Policy
- EOL Firmware        - No Rate Limiting    - Public Read ACL
- Split-Tunnel Open   - Verbose JSON Errors - Wildcard (*) Permissions
                                                 │
                                                 ▼
                                            [Finding 4]
                                            Internal Containerized
                                            Billing Web App
```

**Audit Findings:**
* **Finding 1:** An external Shodan scan reveals a decommissioned, end-of-life VPN concentrator still physically connected to the datacenter edge router with UDP Port 500 and TCP Port 443 open to `0.0.0.0/0`.
* **Finding 2:** A mobile application backend exposes an unauthenticated `/api/v1/users/{id}` endpoint that returns full customer profile objects simply by incrementing the numeric `{id}` parameter in the HTTP request.
* **Finding 3:** A cloud storage bucket used for staging customer invoices is configured with public read permissions, and the attached compute instance profile grants `s3:*` across all organizational resources.
* **Finding 4:** A custom customer-facing web portal accepts unsanitized user file uploads and renders them directly inside the browser DOM without input validation.

**Tasks:**
1. Match **Finding 1 through Finding 4** to its corresponding **Attack Surface Category**:
   * **Categories:** `Perimeter Attack Surface`, `API Attack Surface`, `Cloud Attack Surface`, `Application Attack Surface`
2. Which specific finding above represents a **Shadow / Orphaned Asset** expanding the organization's external footprint, and what is the most direct way to eliminate that specific attack surface?

### Section 2: Scenario-Based Multiple-Choice Questions (MCQs)

#### Question 1
An attacker sends an email to a company's accounts payable department containing an attached PDF invoice for a fake software subscription renewal. The email contains no clickable links or malicious macros; instead, it lists a toll-free customer service phone number to call if the recipient wishes to cancel the \$4,999 charge before the end of the business day. When the employee calls the number, a fake representative walks them through installing a remote desktop tool.

Which combination of threat vectors is being used in this hybrid attack?

* A. Smishing and supply chain compromise
* B. Phishing and vishing
* C. Unsecure wireless and removable media
* D. Watering hole and API enumeration

#### Question 2
A healthcare network contracts with a third-party Managed Service Provider (MSP) to handle night-shift server monitoring and patch management. Threat actors infiltrate the MSP's central management console and use the trusted remote monitoring and management (RMM) agent to push ransomware simultaneously to 40 downstream hospital clients.

Which threat vector was exploited to compromise the healthcare network?

* A. Removable media
* B. Supply chain / vendor compromise
* C. Unsecure wireless network
* D. Vishing

#### Question 3
During a penetration test, an assessor inspects the network traffic generated by a company's single-page web application. The assessor notices calls made to `https://api.corp.example/v2/export` and tests changing the path to `https://api.corp.example/v1/export`. The `/v1/` endpoint is still active, lacks the authentication checks added in `/v2/`, and dumps the entire user database in JSON format.

Which attack surface did the penetration tester successfully exploit?

* A. Human attack surface
* B. Removable media surface
* C. API attack surface
* D. Physical perimeter surface

#### Question 4
A security awareness team wants to test whether employees at a high-security research facility will bypass physical media policies. The team scatters 25 USB flash drives branded with the company logo across the employee parking lot and cafeteria tables. When plugged into a computer, the drives register as a USB keyboard and execute a harmless PowerShell script that reports the workstation hostname to the security team.

Which threat vector is being simulated during this assessment?

* A. Supply chain hardware interdiction
* B. Removable media
* C. Smishing
* D. Evil Twin wireless vector

#### Question 5
Several executives at an enterprise report receiving urgent SMS messages on their personal smartphones claiming their corporate payroll direct deposit accounts have been suspended due to a routing error, along with a shortened URL to verify their banking details.

How should the SOC classify this threat vector?

* A. Vishing
* B. Smishing
* C. Whaling via removable media
* D. Cloud API injection

#### Question 6
A Chief Information Security Officer (CISO) orders the immediate decommissioning of legacy FTP servers, removal of unused administrative plugins on the public corporate website, and strict firewall blocking of all non-essential inbound ports on edge routers.

Which strategic security concept is the CISO executing?

* A. Threat actor attribution
* B. Attack surface reduction
* C. Deception grid deployment
* D. Cryptographic key escrow

#### Question 7
An organization transitions its on-premises infrastructure to an Infrastructure-as-a-Service (IaaS) cloud provider. While reviewing the environment, a security architect notes that developers frequently spin up temporary virtual machines with public IP addresses, attach overly permissive identity roles, and leave management consoles (such as SSH and RDP) exposed to the internet without routing through a jump host.

Which attack surface has expanded most significantly due to these practices?

* A. Cloud and perimeter attack surface
* B. Human and social engineering attack surface
* C. Removable media attack surface
* D. Local wireless attack surface

#### Question 8
A remote employee working from a crowded commuter train connects their tablet to a public Wi-Fi hotspot that requires no password or authentication. Shortly afterward, an attacker sitting two rows behind the employee captures unencrypted session traffic and performs an active Man-in-the-Middle (MitM) attack.

Which threat vector enabled the attacker to intercept the employee's traffic?

* A. Supply chain compromise
* B. Unsecure wireless network
* C. Smishing
* D. Vishing
