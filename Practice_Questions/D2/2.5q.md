# CompTIA Security+ (SY0-701) Practice Exam

## Domain 2.0: Threats, Vulnerabilities, and Mitigations

### Objective 2.5: Given a scenario, implement mitigation techniques to secure the enterprise

### Section 1: Performance-Based Questions (PBQs)

#### PBQ 1: Network Architecture and Segmentation Matrix

**Scenario:**
You are the lead network security architect for a healthcare organization. You are tasked with redesigning the network to ensure maximum security, compliance, and operational efficiency. 

**Task:**
Match the **Business / Security Requirement** to the most appropriate **Mitigation / Architectural Technique**.

**Mitigation / Architectural Techniques:**

* Air-Gapping

* Demilitarized Zone (DMZ)

* Virtual Local Area Network (VLAN)

* Access Control List (ACL)

* Isolation / Quarantine

**Requirements:**

| ID | Business / Security Requirement | Mitigation / Architectural Technique | 
| ----- | ----- | ----- | 
| **1** | The organization needs to host a patient portal web server that is accessible from the public internet, but an attacker compromising this server must not have direct access to the internal enterprise network. |  | 
| **2** | A legacy MRI machine runs an outdated, unsupported operating system that cannot be patched. It must be physically and logically disconnected from all other corporate networks and the internet to prevent malware infection. |  | 
| **3** | The security team detects a workstation communicating with a known command-and-control (C2) server. The incident response team needs to immediately restrict this machine from talking to any other device on the LAN while keeping it powered on for forensics. |  | 
| **4** | The HR department and the Guest Wi-Fi users share the same physical network switches in the main office. However, Guest traffic must be logically separated from HR traffic at Layer 2 to prevent snooping. |  | 
| **5** | The edge router needs a rule configured to explicitly block all incoming traffic attempting to connect over TCP Port 23 (Telnet) from external IP addresses. |  | 

#### PBQ 2: Endpoint and Server Mitigation Strategies

**Scenario:**
A recent vulnerability assessment of your server environment revealed several critical weaknesses. As a systems administrator, you must select the correct mitigation technique to resolve each finding.

**Task:**
Identify the primary **Mitigation Technique** that addresses each specific **Audit Finding**.

**Mitigation Techniques:**

* System Hardening

* Baseline Configuration Enforcement

* Automated Patch Deployment

* Network Segmentation

**Audit Findings:**

| Finding ID | Audit Finding Description | Mitigation Technique | 
| ----- | ----- | ----- | 
| **Finding A** | Over 50% of the Windows servers are missing the last three months of critical Microsoft security updates because the manual update process is frequently forgotten by junior staff. |  | 
| **Finding B** | Newly deployed Linux web servers are often found with different security settings; some have root SSH login enabled, while others do not. There is no standardized template being applied during provisioning. |  | 
| **Finding C** | A database server was compromised because it had several unnecessary software packages installed (e.g., FTP server, print spooler), default manufacturer accounts still active, and unused TCP ports open. |  | 
| **Finding D** | Development servers and production servers are currently on the same subnet. A vulnerability on a test server was exploited, allowing the attacker to easily pivot to the live production database. |  | 

### Section 2: Scenario-Based Multiple-Choice Questions (MCQs)

#### Question 1

A company is deploying a new web application that requires external users to access it over the internet. To protect the internal corporate network, the security team places the web server in a specific subnetwork situated between the public internet and the private LAN, separated by firewalls. 

Which of the following mitigation techniques does this describe?

* A. Air-gapping
* B. Demilitarized Zone (DMZ)
* C. Baseline configuration
* D. Quarantine network

#### Question 2

A security administrator wants to ensure that all newly purchased laptops meet a minimum security standard before being issued to employees. The standard requires full disk encryption to be enabled, guest accounts to be disabled, and a specific endpoint detection and response (EDR) agent to be installed. 

Which of the following processes is the administrator implementing?

* A. Automated patch deployment
* B. Network segmentation
* C. Baseline configuration enforcement
* D. Air-gapping

#### Question 3

An industrial control system (ICS) used to manage a municipal water supply is highly critical and vulnerable to network-based attacks. The Chief Information Security Officer (CISO) mandates that this system must have absolutely no physical or logical connection to the internet or the corporate IT network. 

Which mitigation technique is the CISO utilizing?

* A. VLAN
* B. DMZ
* C. Access Control List (ACL)
* D. Air-gapping

#### Question 4

A network engineer needs to separate the accounting department's network traffic from the marketing department's traffic. Both departments are located on the same floor and connect to the same physical network switch. 

Which technology should the engineer configure to logically separate this traffic at Layer 2?

* A. Demilitarized Zone (DMZ)
* B. Virtual Local Area Network (VLAN)
* C. Air-gap
* D. System hardening

#### Question 5

During a routine audit, a security analyst discovers that several servers have unnecessary services running, default passwords left unchanged, and unused ports open to the network. The analyst recommends disabling the unnecessary services, changing default credentials, and configuring local firewalls to close unused ports. 

What is the overarching term for these combined security actions?

* A. System hardening
* B. Automated patch deployment
* C. Isolation
* D. Network segmentation

#### Question 6

A zero-day vulnerability in a widely used web browser is actively being exploited in the wild. The software vendor releases an emergency security update. To ensure all 5,000 corporate endpoints receive and install this update within 24 hours without requiring user interaction, which mitigation technique should the IT team rely on?

* A. Baseline configuration enforcement
* B. Access Control Lists (ACLs)
* C. Automated patch deployment
* D. Network isolation

#### Question 7

A firewall administrator is configuring a border router. They write a rule that states: `DENY TCP ANY ANY EQ 3389`, which explicitly blocks all inbound Remote Desktop Protocol (RDP) traffic from the internet. 

What specific security mechanism is the administrator utilizing?

* A. Air-gapping
* B. Access Control List (ACL)
* C. VLAN tag
* D. Baseline configuration

#### Question 8

A piece of malware is detected on a user's workstation. To prevent the malware from spreading laterally across the network while allowing the incident response team to remotely investigate the machine, the network team moves the workstation's switch port to a restricted subnet that has no route to the rest of the company. 

What mitigation technique has been applied to the workstation?

* A. Isolation / Quarantine
* B. Demilitarized Zone (DMZ)
* C. System hardening
* D. Air-gapping
