### Section 1: Performance-Based Questions (PBQs)

#### PBQ 1: Incident Response Lifecycle Mapping

**Scenario:**
Your organization recently suffered and recovered from a ransomware infection. You are documenting the incident response timeline for the executive board.

**Task:**
Categorize each **Response Action** into the correct phase of the **Incident Response Lifecycle**.

**Lifecycle Phases:**

* Preparation

* Detection & Analysis (Identification)

* Containment

* Eradication

* Recovery

* Lessons Learned

**Response Actions:**

| ID | Response Action | Lifecycle Phase | 
| ----- | ----- | ----- | 
| **1.** | The incident response team updates the organization's ransomware playbook and conducts a tabletop exercise based on the recent attack to improve future readiness. |  | 
| **2.** | IT staff wipe the infected hard drives, remove the malicious scheduled tasks, and securely re-image the affected servers using a clean, baseline OS installation. |  | 
| **3.** | A SOC analyst receives a SIEM alert indicating high CPU usage and rapid file encryption, correlates it with EDR telemetry, and confirms a true positive ransomware infection. |  | 
| **4.** | The team holds a post-incident meeting to discuss what went right, what went wrong, and how the attacker originally bypassed the email gateway. |  | 
| **5.** | The network engineer unplugs the network cables from the infected servers and disables the compromised user accounts in Active Directory to stop the spread. |  | 
| **6.** | The systems administrator restores the decrypted databases from an offline backup, performs a functional test, and returns the servers to live production status. |  |

**Sequence:**

* Position 1 (Most Volatile): \___\_

* Position 2: \___\_

* Position 3: \___\_

* Position 4: \___\_

* Position 5 (Least Volatile): \___\_

**Task 2: Forensic Terminology Matrix**
Match the **Forensic Concept** to its correct **Definition / Scenario**.

**Concepts:**

* Chain of Custody

* Legal Hold

* Write Blocker

* Bit-by-Bit Imaging

| Definition / Scenario | Forensic Concept | 
| ----- | ----- | 
| **1.** A documented, chronological log showing exactly who collected, handled, transported, and stored a piece of evidence to prove it was not tampered with. |  |

### Section 2: Scenario-Based Multiple-Choice Questions (MCQs)

#### Question 1

An organization is investigating a potential data breach. The human resources and legal departments suspect an employee is involved and inform the IT department that they are preparing for a lawsuit. The IT director immediately suspends the automated 30-day deletion policy for the employee's inbox and cloud storage.

What specific administrative process has the IT director executed?

* A. Chain of Custody

* B. Eradication

* C. Legal Hold

* D. System Isolation

#### Question 2

During a trial prosecuting a cybercriminal, the defense attorney successfully argues that the main hard drive evidence should be thrown out. The attorney proved there was a 48-hour gap where the hard drive was left on an unattended desk, and there is no documentation detailing who had access to it during that time.

Which critical forensic principle was violated?

* A. Order of volatility

* B. Right to audit

* C. E-discovery

* D. Chain of custody

#### Question 3

A security analyst is investigating a compromised workstation that was communicating with a malicious command-and-control (C2) server. The analyst wants to see exactly which external URLs the user navigated to, including the full HTTP GET request parameters.

Which data source would provide the most detailed information for this specific request?

* A. Local Windows Event Viewer (Security Log)

* B. Proxy logs

* C. Layer 3 Firewall logs

* D. Authentication records

#### Question 4

An incident response team responds to a live server that is currently executing a memory-resident (fileless) malware payload. If the team follows standard forensic procedures, which of the following actions should they perform FIRST?

* A. Pull the power plug to immediately halt the malware execution.

* B. Capture a forensic image of the physical hard drive.

* C. Capture a dump of the system's Random Access Memory (RAM).

* D. Review the syslog server for historical authentication failures.

#### Question 5

A SOC analyst is reviewing logs to investigate a suspected privilege escalation attack. The analyst needs to see when a specific user successfully logged into a domain controller, what time they logged off, and whether any failed logon attempts occurred prior to the success.

Which data source is most appropriate for this investigation?

* A. DNS queries

* B. Web Application Firewall (WAF) logs

* C. Windows Security Event logs

* D. Network packet captures (PCAP)

#### Question 6

* B. A bit-level clone automatically decrypts encrypted files.

* C. A bit-level clone captures deleted files, slack space, and hidden partitions.
