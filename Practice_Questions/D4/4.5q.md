#### PBQ 2: Automation Terminology and Concept Mapping

**Scenario:**
You are training a new group of junior security analysts on the differences between various automation concepts and defense tooling. 

**Task:**
Match the **Automation Concept / Tool** to its correct **Definition / Scenario**.

**Concepts / Tools:**

* SIEM (Security Information and Event Management)

* SOAR (Security Orchestration, Automation, and Response)

* Playbook

* Runbook

* API (Application Programming Interface)

**Definitions / Scenarios:**

| ID | Definition / Scenario | Automation Concept / Tool | 
| ----- | ----- | ----- | 
| **1.** | A high-level, human-readable flowchart or checklist that defines the overarching policy and standard operating procedure for handling a specific type of incident (e.g., "Ransomware Response Strategy"). |  | 
| **2.** | The technology that allows the central orchestration platform to securely communicate with and send commands to a third-party firewall, EDR, or ticketing system. |  | 
| **3.** | A platform primarily designed to aggregate logs from across the enterprise, normalize the data, and correlate events to generate alerts for human analysts to review. |  | 
| **4.** | A highly specific, machine-readable script or series of automated steps executed to perform a single operational task (e.g., a Python script that updates a firewall blocklist). |  | 
| **5.** | A platform designed to ingest alerts from other security tools, execute automated workflows across multiple different products, and proactively contain threats with minimal human intervention. |  | 

### Section 2: Scenario-Based Multiple-Choice Questions (MCQs)

#### Question 1

* B. Network Access Control (NAC)
* C. Security Orchestration, Automation, and Response (SOAR)

#### Question 2

* B. Temporarily disable the user's Active Directory account and revoke active session tokens.
* C. Isolate the entire corporate headquarters network from the public internet.
