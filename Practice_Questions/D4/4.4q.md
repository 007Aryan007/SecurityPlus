# CompTIA Security+ (SY0-701) Practice Exam

## Domain 4.0: Security Operations

### Objective 4.4: Given a scenario, apply identity and access management principles

### Section 1: Performance-Based Questions (PBQs)

#### PBQ 1: Access Control Models and PAM Implementation

**Scenario:**
You are the IAM architect for a growing enterprise. You are migrating legacy systems to modern access control models and implementing a Privileged Access Management (PAM) solution to secure administrative accounts.

**Task:**
Match the **IAM Concept / Access Model** to the correct **Implementation Scenario**.

**IAM Concepts / Access Models:**

* Role-Based Access Control (RBAC)

* Attribute-Based Access Control (ABAC)

* Privileged Access Management (PAM) Vaulting

* Just-in-Time (JIT) Access

* Discretionary Access Control (DAC)

**Implementation Scenarios:**

| ID | Implementation Scenario | IAM Concept / Access Model | 
| ----- | ----- | ----- | 
| **1.** | A policy states that access to the financial database is only granted if the user is in the Finance group, the request originates from a corporate IP address, and the current time is between 8:00 AM and 5:00 PM EST. |  | 
| **2.** | When a junior developer is hired, they are automatically assigned to the "Software Engineer" group. The system grants them access to the code repository, Jira, and Slack channels associated with that specific group. |  | 
| **3.** | A database administrator's account normally has standard user permissions. When an emergency fix is required on the production database, the administrator requests elevated privileges, which are granted for exactly two hours before automatically expiring. |  | 
| **4.** | The enterprise requires all shared root passwords for hypervisors and core routers to be stored in a centralized, encrypted system. Administrators must check out the credentials, and the system automatically rotates the password upon check-in. |  | 
| **5.** | The creator of a shared folder on a departmental file server manually assigns read and write permissions to specific colleagues they want to collaborate with. |  | 

#### PBQ 2: Federation, SSO, and Directory Protocols

**Scenario:**
Your organization is integrating various cloud applications, third-party services, and internal directories to create a seamless Single Sign-On (SSO) experience for employees.

**Task:**
Identify the appropriate **Protocol / Standard** that corresponds to each **Use Case Description**.

**Protocols / Standards:**

* SAML (Security Assertion Markup Language)

* OAuth 2.0

* OpenID Connect (OIDC)

* Kerberos

* LDAPS (Lightweight Directory Access Protocol over SSL/TLS)

**Use Case Descriptions:**

| Use Case Description | Protocol / Standard | 
| ----- | ----- | 
| **A.** | An internal Microsoft Active Directory protocol that uses a Key Distribution Center (KDC) to issue Ticket-Granting Tickets (TGT) to users for seamless authentication to local network resources. | 
| **B.** | A web-based SSO standard where the organization's Identity Provider (IdP) passes digitally signed XML statements to a third-party SaaS application (Service Provider), proving the user is authenticated. | 
| **C.** | An authorization framework that allows a user to grant a third-party application limited access to their resources (like allowing a printing app to access Google Drive files) without sharing their actual password. | 
| **D.** | An authentication layer built on top of an authorization framework, utilizing JSON Web Tokens (JWT) and RESTful API calls to verify the identity of an end-user based on authentication performed by an authorization server. | 
| **E.** | A protocol used to query and modify directory services data over a network, secured via TLS on TCP port 636 to prevent eavesdropping on user credentials during directory lookups. | 

### Section 2: Scenario-Based Multiple-Choice Questions (MCQs)

#### Question 1

A company is upgrading its multi-factor authentication (MFA) requirements to defeat sophisticated phishing attacks. They issue hardware security keys to all employees. To log in, an employee inserts the key into their USB port and taps a fingerprint sensor on the key itself.

Which two authentication factors are being utilized in this passwordless workflow?

* A. Something you know and something you exhibit
* B. Something you have and something you are
* C. Something you have and somewhere you are
* D. Something you know and something you have

#### Question 2

A mobile application needs to access a user's cloud-based photo album to apply filters. The user is redirected to the cloud provider's login page, authenticates, and is asked, "Do you want to allow the PhotoFilter App to read your photos?" The app receives an access token but never sees the user's password.

Which protocol is facilitating this delegated access?

* A. Kerberos
* B. SAML
* C. LDAPS
* D. OAuth 2.0

#### Question 3

A systems administrator notices that users in the corporate office are suddenly unable to access internal file shares or intranet portals without manually entering their passwords repeatedly. A network troubleshooting tool reveals that the time on the primary domain controller has drifted 15 minutes ahead of the client workstations.

Which authentication protocol is failing due to this time synchronization issue?

* A. Kerberos
* B. OpenID Connect (OIDC)
* C. OAuth 2.0
* D. RADIUS

#### Question 4

An organization wants to move away from passwords entirely (passwordless authentication) for its web applications. They want to utilize standard public-key cryptography where the user's device generates a key pair, stores the private key securely in a hardware enclave, and uses biometric prompts to unlock it for web authentication.

Which standard should the organization implement to achieve this?

* A. LDAP v3
* B. FIDO2 / WebAuthn
* C. SAML 2.0
* D. TACACS+

#### Question 5

A cloud architect is designing an identity federation between their enterprise and a partner organization. The architect decides to use SAML. In this setup, the partner organization hosts the web application the employees need to access, and the enterprise validates the employees' passwords.

What is the correct terminology for the partner organization's application in this SAML architecture?

* A. The Identity Provider (IdP)
* B. The Ticket Granting Server (TGS)
* C. The Service Provider (SP)
* D. The Key Distribution Center (KDC)

#### Question 6

An IT department implements a Privileged Access Management (PAM) solution. Now, when a network engineer needs to configure a core switch, they must log into the PAM portal and click a button to initiate a session. The PAM solution logs into the switch automatically on the engineer's behalf, recording the session. The engineer never actually knows the switch's root password.

Which specific PAM capability does this scenario describe?

* A. Attribute-Based Access Control (ABAC)
* B. Credential Vaulting / Password Brokering
* C. Single Sign-On (SSO) Federation
* D. Just-in-Time (JIT) access

#### Question 7

A large university uses a complex access control system. A student is allowed to access the online library database, but only if they are currently enrolled in a minimum of three classes, have paid their tuition, and are accessing the portal from a device registered in the university's MDM system.

Which access control model relies on evaluating these multiple contextual variables?

* A. Role-Based Access Control (RBAC)
* B. Discretionary Access Control (DAC)
* C. Attribute-Based Access Control (ABAC)
* D. Mandatory Access Control (MAC)

#### Question 8

To prevent credential dumping and lateral movement, a security team enforces a policy where Domain Admin accounts are completely deactivated by default. If an administrator needs to perform a high-level task, they must submit a ticket. If approved, the account is temporarily enabled for one hour and automatically disabled afterward.

Which security concept does this process demonstrate?

* A. Just-in-Time (JIT) access
* B. OpenID Connect (OIDC)
* C. Role-Based Access Control (RBAC)
* D. Passwordless authentication
