# CompTIA Security+ (SY0-701) Practice Exam

## Domain 4.0: Security Operations

### Objective 4.2: Given a scenario, apply concepts of asset and vulnerability management

### Section 1: Performance-Based Questions (PBQs)

#### PBQ 1: Vulnerability Scan Validation Matrix

**Scenario:**
You are a vulnerability management analyst reviewing the weekly automated vulnerability scan report for the enterprise network. You must validate the scanner's findings by comparing them to system configurations and real-world conditions.

**Task:**
Categorize each **Scan Finding** into its correct **Validation Status** (True Positive, False Positive, True Negative, False Negative).

**Validation Statuses:**

* **True Positive:** The scanner reported a vulnerability, and the vulnerability actually exists.
* **False Positive:** The scanner reported a vulnerability, but the vulnerability does not actually exist (e.g., it is already mitigated by a compensating control).
* **True Negative:** The scanner did not report a vulnerability, and the system is indeed secure.
* **False Negative:** The scanner did not report a vulnerability, but a vulnerability actually exists and was missed.

**Scan Findings:**

| ID | Scan Finding / Reality | Validation Status |
|---|---|---|
| **1.** | The scanner flagged a Linux web server for running an outdated, vulnerable version of Apache. However, the system administrator manually verified that the Linux distribution vendor had already "backported" the security patch into this older version. | |
| **2.** | The scanner alerted that a network switch is using default SNMP community strings (`public`/`private`). Upon manual testing, you successfully connect to the switch using the word `public`. | |
| **3.** | The scanner reported that a workstation was completely secure and fully patched. The next day, that exact workstation is compromised by an attacker exploiting a misconfigured registry key that the scanner's signature database was not programmed to check for. | |
| **4.** | The scanner flagged an internal HR application for being vulnerable to SQL injection. You review the application code and determine that input sanitization and parameterized queries were never implemented by the developer. | |

#### PBQ 2: Asset Lifecycle Management

**Scenario:**
An organization has a strict hardware and software asset lifecycle management policy. You are tasked with mapping specific security and operational actions to their correct phase in the asset lifecycle.

**Task:**
Match the **Security/Operational Action** to the correct **Lifecycle Phase**.

**Lifecycle Phases:**

* Phase 1: Procurement / Acquisition
* Phase 2: Deployment / Provisioning
* Phase 3: Operations / Maintenance
* Phase 4: Decommissioning / Disposal

**Actions:**

| Security / Operational Action | Lifecycle Phase |
|---|---|
| **A.** Applying the initial secure configuration baseline, assigning a physical RFID asset tag, and adding the device to the central CMDB (Configuration Management Database). | |
| **B.** Performing NIST 800-88 compliant media sanitization (crypto-shredding or physical destruction) and revoking software licenses. | |
| **C.** Conducting a supply chain risk assessment and vetting the third-party vendor's security posture before signing a purchase order. | |
| **D.** Conducting weekly automated vulnerability scans, applying monthly OS patches, and monitoring endpoint telemetry via EDR. | |

### Section 2: Scenario-Based Multiple-Choice Questions (MCQs)

#### Question 1

A security analyst is reviewing a vulnerability alert from CISA regarding a new critical flaw in a widely used firewall appliance. The alert references a specific identifier formatted as `CVE-2024-12345`. 

What does this identifier primarily provide to the analyst?

* A. The numeric score dictating the exact severity of the vulnerability.
* B. The automated patch script required to fix the vulnerability.
* C. A standardized dictionary reference for the publicly known information security vulnerability.
* D. The network port that the attacker will use to exploit the firewall.

#### Question 2

A vulnerability scanner reports a flaw in a database server, assigning it a CVSS v3.1 Base Score of 9.8. 

Based on standard vulnerability management frameworks, how should the security team prioritize this finding?

* A. Low priority; it should be patched during the next quarterly cycle.
* B. Medium priority; it requires mitigation within 30 days.
* C. High priority; it requires mitigation within 14 days.
* D. Critical priority; it requires immediate emergency remediation and triage.

#### Question 3

An organization has thousands of virtual machines (VMs) spread across multiple cloud providers. The security team is struggling to keep track of which VMs belong to which department, making it difficult to assign patching responsibilities. 

Which of the following is the most efficient asset management technique to resolve this issue?

* A. Implementing MAC address filtering.
* B. Implementing a comprehensive cloud asset tagging strategy (e.g., `Owner: Marketing`, `Environment: Production`).
* C. Disabling auto-scaling in the cloud environment.
* D. Air-gapping the virtual machines.

#### Question 4

During a routine patch management workflow, a systems administrator discovers that deploying a vendor's latest security patch causes the company's proprietary accounting software to crash. 

What is the correct next step in a mature patch remediation workflow?

* A. Immediately deploy the patch to production to ensure security, and tell the accounting department to wait for a software fix.
* B. Do not apply the patch; document the risk and deploy a compensating control (such as a WAF rule or strict network isolation) while a permanent fix is developed.
* C. Uninstall the accounting software and find an open-source alternative.
* D. Delete the server from the asset inventory so the vulnerability scanner stops alerting on it.

#### Question 5

A security engineer runs a credentialed vulnerability scan against a critical application server. The scan report shows zero vulnerabilities. However, a penetration tester is able to easily exploit a known missing patch on the server a week later. 

Which of the following describes the result of the vulnerability scan?

* A. True Positive
* B. False Positive
* C. True Negative
* D. False Negative

#### Question 6

An IT department uses an active scanning tool that pings IP addresses and interrogates open ports across the entire corporate subnet every Sunday night to find unauthorized or unmanaged devices (Rogue IT). 

Which process is the IT department performing?

* A. Asset discovery
* B. Patch remediation
* C. CVSS scoring
* D. Data decommissioning

#### Question 7

A company is preparing to retire a fleet of old employee laptops and donate them to a local school. Before the laptops leave the facility, the IT team uses a specialized software tool to overwrite the entire hard drive with random zeroes and ones multiple times. 

Which phase of the asset lifecycle is being executed, and what specific action is taking place?

* A. Procurement; Asset tagging
* B. Operations; Baseline configuration
* C. Decommissioning; Data sanitization/wiping
* D. Deployment; Image deployment

#### Question 8

When reviewing a Common Vulnerability Scoring System (CVSS) vector string, which of the following metrics would heavily increase the severity score of a vulnerability?

* A. The vulnerability requires the attacker to have physical access to the machine.
* B. The vulnerability requires high privileges (Admin) to exploit.
* C. The vulnerability can be exploited over the network without any user interaction or authentication.
* D. The vulnerability has a high complexity, requiring specific race conditions to be met.
