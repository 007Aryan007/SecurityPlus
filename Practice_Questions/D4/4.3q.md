#### PBQ 2: SIEM Operations and Logic

**Scenario:**
You are a SOC analyst configuring a Security Information and Event Management (SIEM) system. You must organize how data is handled and write logical rules to trigger alerts.

**Task 1: SIEM Terminology**
Match the **SIEM Concept** to its definition.

* **Log Aggregation**

* **Data Normalization**

* **Correlation**

| Definition | SIEM Concept | 
| ----- | ----- | 
| **A.** Taking raw log fields from a Cisco router, a Windows Server, and an Apache web server and formatting them into a standard, uniform schema (e.g., standardizing `src_ip`, `SourceAddress`, and `IP_In` to a single `source_ip` field). |  | 
| **B.** The process of centrally collecting and archiving event logs from hundreds of disparate network devices and servers into a single secure repository. |  | 
| **C.** Analyzing relationships between multiple distinct logs across different systems to identify a larger attack pattern (e.g., linking a firewall block event to an endpoint antivirus alert based on matching timestamps and IP addresses). |  | 

**Task 2: Alerting Rule Logic**
You need to write a SIEM alerting rule to detect an "Impossible Travel" scenario (a user logging in from two geographically distant locations in an impossibly short timeframe). Fill in the logical operators based on the logs below.

*Log Event A:* Successful Login for `User: J.Smith` from `IP: 198.51.100.4 (New York, USA)` at `08:00:00 AM`.
*Log Event B:* Successful Login for `User: J.Smith` from `IP: 203.0.113.8 (Tokyo, Japan)` at `08:15:00 AM`.

**Trigger Alert IF:**
(Event A [Action] == "Success" AND Event B [Action] == "Success")
**AND** (Event A [User] `________` Event B [User])
**AND** (Event A [GeoLocation] `________` Event B [GeoLocation])
**AND** (Time difference between Event A and Event B is `<` 12 hours)
