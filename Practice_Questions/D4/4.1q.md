# CompTIA Security+ (SY0-701) Practice Exam

## Domain 4.0: Security Operations

### Objective 4.1: Given a scenario, apply common security techniques to computing resources

### Section 1: Performance-Based Questions (PBQs)

#### PBQ 1: Endpoint Security Control Mapping

**Scenario:**
You are a security engineer tasked with hardening the computing resources for a mid-sized enterprise. You must select the most appropriate technical control to mitigate specific risks outlined in a recent security audit.

**Task:**
Match the **Security Requirement / Risk** to the most appropriate **Security Control**.

**Security Controls:**

* Host-Based Firewall

* Application Allowlist

* Sandboxing

* Secure Baseline (Configuration Template)

* Disabling Unnecessary Ports/Services

**Requirements / Risks:**

| ID | Security Requirement / Risk | Security Control | 
| ----- | ----- | ----- | 
| **1.** | Malware infections are occurring because employees are downloading and running unapproved freeware. The CISO mandates a "default deny" posture where only explicitly approved executables can run on corporate machines. |  | 
| **2.** | Incident responders need a safe, isolated virtual environment to execute a suspicious file attached to a phishing email and monitor its behavior without risking the underlying operating system. |  | 
| **3.** | A new Windows Server was deployed with the Print Spooler and FTP server enabled by default, even though it is only meant to be a web server. These must be turned off to reduce the attack surface. |  | 
| **4.** | Remote employees working from coffee shops are vulnerable to lateral attacks from other devices on the same public Wi-Fi network. You must block all inbound connection requests directly at the employee's laptop. |  | 
| **5.** | The IT department struggles with configuration drift; new laptops are being provisioned with inconsistent security settings. You need to deploy a standardized, pre-approved OS configuration image to all new machines. |  | 

#### PBQ 2: Mobile Device Management (MDM) Configuration

**Scenario:**
Your organization is implementing a Bring Your Own Device (BYOD) policy. To secure corporate data on employee-owned smartphones, you are configuring the enterprise Mobile Device Management (MDM) platform.

**Task:**
Identify the correct **MDM Feature / Concept** that matches each **Implementation Scenario**.

**MDM Features / Concepts:**

* Containerization (Workspace Isolation)

* Geofencing

* Remote Wipe

* Storage Segmentation

* Screen Lock / Biometric Enforcement

**Scenarios:**

| Implementation Scenario | MDM Feature / Concept | 
| ----- | ----- | 
| **A.** | Ensuring that if an employee's phone is lost in a taxi, the IT department can send a command over the cellular network to securely erase all data on the device. |  | 
| **B.** | Creating a strictly isolated, encrypted area on the employee's personal phone specifically for corporate email and apps, preventing data from leaking into personal apps. |  | 
| **C.** | Configuring a policy that automatically disables the device's camera and restricts access to specific confidential files when the device's GPS indicates it is physically inside the corporate R&D facility. |  | 
| **D.** | Mandating that all devices enrolling in the corporate network must have a 6-digit PIN, facial recognition, or fingerprint authentication enabled to wake the device from sleep mode. |  | 

### Section 2: Scenario-Based Multiple-Choice Questions (MCQs)

#### Question 1

A system administrator is hardening a newly installed database server. The administrator runs a port scan and notices that TCP port 21 (FTP), TCP port 23 (Telnet), and TCP port 80 (HTTP) are open. The administrator immediately stops these processes and prevents them from starting on boot.

Which security principle is the administrator primarily applying?

* A. Sandboxing

* B. Disabling unnecessary ports and services

* C. Network segmentation

* D. Application allowlisting

#### Question 2

An organization wants to adopt a zero-trust approach to endpoint software execution. Instead of relying on antivirus signatures to block known bad files, they implement a policy where absolutely no software can run on a workstation unless its cryptographic hash is pre-approved by the IT department.

Which technique does this describe?

* A. Application Deny List (Blocklist)

* B. Host-based intrusion detection

* C. Application Allow List (Whitelist)

* D. Hardware Root of Trust

#### Question 3

A cybersecurity analyst receives a suspicious `.exe` file from a user who suspects it is malware. The analyst wants to execute the file to see if it attempts to modify registry keys or reach out to external command-and-control servers, but needs to do so without risking the corporate network.

Which of the following environments should the analyst use?

* A. A sandbox

* B. A jump box

* C. An active directory domain controller

* D. A production honeypot

#### Question 4

An enterprise is rolling out 500 new Windows laptops. To ensure compliance, the security team uses Group Policy Objects (GPOs) to enforce minimum password lengths, disable guest accounts, and enable full disk encryption across all machines before they are handed to users.

What is the term for this standardized set of security configurations?

* A. Application control

* B. Endpoint detection and response (EDR)

* C. Secure baseline

* D. Containerization

#### Question 5

A traveling sales representative frequently connects to unsecured wireless networks in airports and hotels. To prevent attackers on the same local network from accessing file shares on the representative's laptop, which control should be configured on the laptop itself?

* A. Mobile Device Management (MDM)

* B. Host-based firewall

* C. Sandboxing

* D. Network-based Intrusion Prevention System (NIPS)

#### Question 6

An organization implements a Bring Your Own Device (BYOD) program. An employee leaves the company on bad terms, and the IT department needs to immediately revoke the employee's access to corporate emails and delete corporate documents stored on their personal smartphone. However, they must not delete the employee's personal photos or text messages.

Which MDM concept allows the IT department to accomplish this?

* A. Geofencing

* B. Full device encryption

* C. Containerization / Storage segmentation

* D. Host-based firewall

#### Question 7

Modern malware frequently alters its signature to evade traditional antivirus software. To counter this, an organization deploys a security agent to all endpoints that continuously monitors running processes, memory behavior, and network connections to detect and autonomously isolate anomalous activity.

Which of the following best describes this solution?

* A. Endpoint Detection and Response (EDR) / Endpoint Protection Platform (EPP)

* B. Mobile Device Management (MDM)

* C. Application deny listing

* D. Data Loss Prevention (DLP)

#### Question 8

An employee attempts to copy a sensitive corporate spreadsheet from their managed work email application into their personal cloud storage application on the same smartphone. The action is blocked, and a prompt appears stating: "Corporate policy prevents sharing data outside of managed applications."

Which technology is primarily responsible for enforcing this policy on the mobile device?

* A. Host-based firewall

* B. Sandboxing

* C. Virtual Private Network (VPN)

* D. Mobile Device Management (MDM)
