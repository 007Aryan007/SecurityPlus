# CompTIA Security+ (SY0-701) Practice Exam

## Domain 3.0: Architecture and Design

### Objective 3.2: Given a scenario, implement enterprise infrastructure security principles

### Section 1: Performance-Based Questions (PBQs)

#### PBQ 1: Infrastructure Component Mapping

**Scenario:**
You are reviewing the high-level network topology for a financial services company. The architecture includes various intermediate appliances and servers designed to control traffic flow and secure backend systems.

**Task:**
Match the **Infrastructure Component** to its corresponding **Primary Function / Location**.

**Infrastructure Components:**

* Forward Proxy

* Reverse Proxy

* Jump Box (Bastion Host)

* Defense-in-Depth

**Functions / Locations:**

| Component | Primary Function / Location | 
| ----- | ----- | 
| **1.** | Placed at the internet edge in front of internal web servers. It intercepts incoming client requests from the internet, performs SSL decryption, caches content, and forwards the requests to the backend servers, hiding the internal IP addresses from the public. | 
| **2.** | An overarching architectural strategy that involves layering multiple independent security controls (e.g., perimeter firewall, endpoint EDR, strong password policies, and data encryption) so that if one control fails, others remain to block an attack. | 
| **3.** | Placed on the internal network edge. It intercepts outgoing requests from internal employee workstations to the internet, enforces web content filtering policies, and masks the employees' internal IP addresses from external websites. | 
| **4.** | A highly secured, heavily monitored server positioned in a distinct management subnet (or DMZ). Administrators cannot connect directly to internal database servers; they must first authenticate to this hardened server and initiate their administrative sessions from there. | 

#### PBQ 2: Secure Protocol Remediation

**Scenario:**
A recent vulnerability scan has flagged several legacy, plaintext protocols actively being used across the enterprise network. You have been tasked with migrating these vulnerable services to their modern, secure equivalents.

**Task:**
Identify the appropriate **Secure Protocol** to replace the **Legacy / Insecure Protocol**.

**Secure Protocols:**

* IPsec

* TLS / HTTPS

* SSH

* SFTP

* DNSSEC

* SNMPv3

**Remediation Matrix:**

| Finding | Legacy / Insecure Protocol in Use | Secure Protocol Replacement | 
| ----- | ----- | ----- | 
| **A** | Administrators are managing Cisco routers remotely using **Telnet** (Port 23), which transmits commands and passwords in cleartext. |  | 
| **B** | The monitoring system is polling network switches for performance metrics using **SNMPv1 / v2c** (Port 161), exposing the community string to network sniffers. |  | 
| **C** | The public-facing corporate website is currently accepting login credentials over **HTTP** (Port 80). |  | 
| **D** | Automated scripts are transferring daily backup archives to a vendor using traditional **FTP** (Port 21). |  | 
| **E** | Unencrypted generic routing encapsulation (GRE) tunnels are being used to connect the main headquarters to the remote branch office over the public internet. |  | 
| **F** | The organization's domain name system is vulnerable to cache poisoning and spoofing because queries lack cryptographic authentication and integrity checks. |  | 

### Section 2: Scenario-Based Multiple-Choice Questions (MCQs)

#### Question 1

A company’s security policy requires that any administrator wishing to manage internal Active Directory domain controllers from a remote location must first connect to a specific, heavily locked-down server in the DMZ. All administrative tools and SSH sessions must be launched from this intermediate server.

Which of the following infrastructure concepts does this intermediate server represent?

* A. Reverse Proxy

* B. Jump Box (Bastion Host)

* C. Forward Proxy

* D. Load Balancer

#### Question 2

A network administrator needs to establish a permanent, secure site-to-site connection between the company's New York headquarters and its London branch over the public internet. The connection must provide data confidentiality and integrity at the network layer (Layer 3) for all traffic passing between the sites.

Which of the following protocols is best suited for this task?

* A. SFTP

* B. SSH

* C. IPsec

* D. TLS

#### Question 3

An organization deploys an appliance on its internal network that intercepts all employee web traffic destined for the internet. The appliance inspects the URLs, blocks access to known malicious domains, and logs all outbound web activity.

Which of the following infrastructure components has been deployed?

* A. Jump Box

* B. Forward Proxy

* C. Reverse Proxy

* D. VPN Concentrator

#### Question 4

To protect against DNS spoofing and cache poisoning attacks, a security engineer decides to implement a solution that adds cryptographic digital signatures to the company's DNS records, allowing clients to verify the origin and integrity of the DNS responses they receive.

Which protocol is the engineer implementing?

* A. SNMPv3

* B. IPsec

* C. DNSSEC

* D. HTTPS

#### Question 5

A retail company uses a layered approach to security. They employ a perimeter next-generation firewall, segment their network with VLANs, require multi-factor authentication (MFA) for all user logins, install endpoint detection and response (EDR) on all devices, and encrypt all customer data at rest.

Which enterprise security principle does this scenario best illustrate?

* A. Implicit Trust

* B. Defense-in-Depth

* C. System Hardening

* D. Immutable Infrastructure

#### Question 6

A security analyst is hardening the configuration of all corporate network switches and routers. They need to ensure that the network management system can pull health metrics from these devices securely, providing both encryption and strong authentication to prevent eavesdropping and unauthorized configuration changes.

Which protocol should the analyst configure on the network devices?

* A. SNMPv3

* B. SSH

* C. TLS

* D. SFTP

#### Question 7

The e-commerce team wants to improve the performance and security of their customer-facing web application. They deploy an appliance in the DMZ that terminates the inbound SSL/TLS connections from customers, inspects the traffic for web exploits, and then passes the safe requests to the internal web servers.

Which of the following best describes this appliance?

* A. Forward Proxy

* B. Reverse Proxy

* C. Jump Box

* D. Honeypot

#### Question 8

A vendor requires your company to send a daily batch file containing confidential inventory data. The vendor specifies that the file must be transferred over a protocol that uses SSH (Secure Shell) to provide an encrypted transport layer for the file transfer process.

Which protocol must your company use to meet this requirement?

* A. TFTP

* B. FTPS

* C. HTTPS

* D. SFTP
