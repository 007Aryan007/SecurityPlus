* SaaS (Software as a Service)

#### PBQ 2: Infrastructure as Code (IaC) & Modern Architecture Terminology

**Scenario:**
You are reviewing a technical document outlining the transition to a modern DevSecOps pipeline. Some of the architectural terms have been left blank.

**Task:**
Match the correct **Architectural Concept** to the corresponding **Definition / Scenario**.

**Architectural Concepts:**
* Edge Computing
* Serverless
* Configuration Drift
* Immutable Infrastructure
* SCADA (Supervisory Control and Data Acquisition)
* Automation Templates (e.g., Terraform, CloudFormation)

**Definitions / Scenarios:**

| ID | Definition / Scenario | Architectural Concept |
| :--- | :--- | :--- |
| **A** | Using declarative code files (like JSON or YAML) to automatically provision, configure, and manage infrastructure rather than clicking through a graphical console. | |
| **B** | A paradigm where virtual servers are never modified after they are deployed. If a patch is needed, the old server is destroyed and a completely new, patched server is deployed from a base image. | |
| **C** | A developer manually logs into a production web server via SSH to tweak a firewall rule, causing the server's state to silently differ from the master baseline defined in the code repository. | |
| **D** | Executing code functions in the cloud triggered by events (e.g., AWS Lambda), where the organization does not provision any underlying operating systems and is billed only for the exact milliseconds the code runs. | |
| **E** | Processing data locally on smart sensors and local gateways at a manufacturing plant to reduce latency and bandwidth usage, rather than sending all raw data back to a centralized cloud. | |
| **F** | A specialized industrial control system used to centrally monitor and manage physical equipment like water valves, pipeline pressure sensors, and electrical grid switches. | |

### Section 2: Scenario-Based Multiple-Choice Questions (MCQs)

#### Question 1
A retail company is deploying thousands of smart surveillance cameras across its stores. To reduce the massive bandwidth required to stream 4K video to the centralized cloud for facial recognition, the company installs localized micro-servers in each store to process the video locally and only send alerts to the central cloud. 

Which architecture model does this represent?
* A. Serverless computing
* B. Edge computing
* C. Immutable infrastructure
* D. Platform as a Service (PaaS)

#### Question 2
A software development team wants to deploy a new web application. They want to write the code in Python and deploy it to the cloud without having to manage the underlying Linux operating system, apply OS security patches, or configure the web server software. 

Which cloud service model best fits this requirement?
* A. IaaS
* B. SaaS
* C. PaaS
* D. On-premises

#### Question 3
An organization’s security policy dictates that production web servers should never be patched or updated while running. Instead, when a new security update is released, the IT team updates the master virtual machine image, deploys a completely new fleet of web servers from the new image, and tears down the old ones.

What concept is the organization enforcing?
* A. Configuration drift
* B. Mutable infrastructure
* C. Immutable infrastructure
* D. Multi-cloud deployment

#### Question 4
A manufacturing facility utilizes programmable logic controllers (PLCs) to manage the robotic arms on an assembly line. These PLCs report back to a centralized monitoring system that allows engineers to view real-time production metrics and adjust machine speeds. 

What type of specialized environment is this?
* A. Serverless architecture
* B. ICS / SCADA
* C. Software as a Service (SaaS)
* D. Multi-cloud

#### Question 5
During an audit, a security engineer discovers that several servers in the cloud environment have different SSH port configurations and mismatched local user accounts, despite all of them originally being deployed from the exact same automation template six months ago. 

Which of the following issues has occurred?
* A. Configuration drift
* B. Immutable deployment
* C. Cloud bursting
* D. Edge processing failure

#### Question 6
An enterprise decides to host its customer-facing web servers on a public cloud provider (like AWS) to take advantage of elastic scalability. However, due to strict regulatory compliance, the backend database containing sensitive customer records must remain on physical servers located in the company's own privately owned datacenter. 

Which cloud deployment model is being used?
* A. Private cloud
* B. Multi-cloud
* C. Public cloud
* D. Hybrid cloud

#### Question 7
A developer writes a short script that resizes images. Instead of provisioning a virtual machine to run this script, the developer uploads the code directly to the cloud provider. The cloud provider automatically executes the code only when a user uploads a new image, billing the developer for the exact compute time used. 

Which architecture model is described here?
* A. Edge computing
* B. Serverless
* C. Infrastructure as Code (IaC)
* D. On-premises

#### Question 8
A company is using HashiCorp Terraform (Infrastructure as Code) to manage its cloud environments. Which of the following is a primary security benefit of using IaC automation templates over manual provisioning?
* A. It automatically remediates zero-day vulnerabilities in application code.
* B. It ensures consistent, repeatable deployments that eliminate human error and misconfigurations.
* C. It prevents the need for access control lists (ACLs) and firewalls.
* D. It encrypts all data at rest by default without requiring a key management system.
