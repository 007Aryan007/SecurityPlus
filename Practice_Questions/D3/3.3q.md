### Section 2: Scenario-Based Multiple-Choice Questions (MCQs)

#### Question 1

A hospital needs to train a new AI model using thousands of patient medical records. To comply with HIPAA, the security team removes all names, addresses, Social Security Numbers, and other identifying information from the dataset before handing it over to the data science team. 

Which data protection method is the security team employing?

* A. Tokenization

* B. Data masking

* C. Sanitization / Anonymization

* D. Crypto-shredding

#### Question 2

A security administrator configures a policy on the corporate email gateway. The policy scans all outgoing emails and automatically blocks any message containing a 9-digit number formatted as `XXX-XX-XXXX`. 

Which technology is the administrator utilizing?

* A. Endpoint Detection and Response (EDR)

* B. Data Loss Prevention (DLP)

* C. Intrusion Prevention System (IPS)

* D. Digital Rights Management (DRM)

#### Question 3

An organization has decided to migrate from standard database encryption to a tokenization solution for its payment processing systems. Which of the following is the primary security advantage of tokenization over traditional encryption?

* A. Tokens are cryptographically tied to the original data and can be easily reversed if the tokenization server goes offline.

* B. Tokenization is natively supported by all legacy operating systems without third-party software.

* C. The tokenized data retains the original format but has no mathematical relationship to the original sensitive data, rendering it useless to attackers.

* D. Tokens automatically encrypt data while it is in transit over unsecured networks.

#### Question 4

A call center agent needs to verify a customer's identity over the phone. When the agent pulls up the customer's profile on their screen, the application displays the credit card number as `XXXX-XXXX-XXXX-4921`. 

Which data securing method is being demonstrated?

* A. Encryption

* B. Hashing

* C. Masking

* D. DLP

#### Question 5

A cloud administrator is decommissioning a virtual machine that previously hosted highly classified military research. According to NIST 800-88 guidelines, the administrator deletes the encryption keys used to secure the data volume, rendering the ciphertext permanently unrecoverable, rather than writing over the entire disk with zeros.

What specific sanitization technique is the administrator using?

* A. Degaussing

* B. Crypto-shredding

* C. Tokenization

* D. Purging via block-level overwrite

#### Question 6

An employee attempts to copy a folder containing confidential quarterly earnings reports to a personal USB flash drive. The transfer is immediately blocked, and a pop-up alert notifies the user that moving this classification of data to removable media is prohibited.

Which specific type of solution enforced this block?

* A. Network DLP

* B. Cloud Access Security Broker (CASB)

* C. Endpoint DLP

* D. Antivirus software

#### Question 7

A company classifies its data into four tiers: Public, Internal, Confidential, and Restricted. A document contains the company's proprietary source code for its flagship software. If this document falls into the hands of a competitor, it would cause catastrophic financial damage to the organization.

Based on standard classification models, which tier should this document be assigned to?

* A. Restricted

* B. Internal

* C. Public

* D. Confidential

#### Question 8

Protecting data in transit and data at rest is commonly achieved through standard encryption protocols like TLS and AES. However, protecting data while it is actively being processed by a CPU or stored in RAM is historically much more difficult. 

Which emerging technology is specifically designed to secure "Data in Use"?

* A. Secure Enclaves / Confidential Computing

* B. IPsec VPNs

* C. Full Disk Encryption (FDE)

* D. Endpoint Data Loss Prevention
