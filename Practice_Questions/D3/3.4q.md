### Section 1: Performance-Based Questions (PBQs)

#### PBQ 1: RAID Configuration Matrix

**Scenario:**
You are the lead systems engineer outfitting a new datacenter. You must choose the appropriate Redundant Array of Independent Disks (RAID) configuration for five different servers based on their specific performance and fault-tolerance requirements.

**Task:**
Match each **Server Requirement** to the correct **RAID Level**.

**RAID Levels:**

* RAID 0

* RAID 1

* RAID 5

* RAID 6

* RAID 10

**Server Requirements:**

| Server Use Case | Description of Requirement | RAID Level | 
| ----- | ----- | ----- | 
| **Server A (Log Aggregator)** | Requires a minimum of 4 drives. Needs excellent read/write performance and high fault tolerance. Data is striped across mirrored pairs. |  | 
| **Server B (Video Cache)** | Requires maximum possible read/write performance. Fault tolerance is not required, as data is temporary and easily replaced. If one drive fails, all data is lost. |  | 
| **Server C (File Server)** | Requires a minimum of 3 drives. Uses distributed parity. Can survive the failure of exactly 1 drive without losing data. Good read speeds, slightly slower write speeds. |  | 
| **Server D (OS Drive)** | Requires exactly 2 drives. Exact copies of data are written to both drives simultaneously (mirroring). If one drive fails, the system continues running perfectly. |  | 
| **Server E (Archive DB)** | Requires a minimum of 4 drives. Uses double distributed parity. Must be able to survive the simultaneous failure of any 2 drives without losing data. |  | 

#### PBQ 2: Disaster Recovery & Backup Strategy Mapping

**Scenario:**
Your organization is finalizing its Disaster Recovery Plan (DRP) and needs to validate its backup and site recovery terminology.

**Task:**
Identify the correct **Term / Concept** that matches each **Scenario Description**.

**Terms / Concepts:**

* Incremental Backup

* Differential Backup

* 3-2-1 Rule

* Hot Site

* Warm Site

* Cold Site

* Snapshot

**Scenarios:**

| Scenario Description | Term / Concept | 
| ----- | ----- | 
| **1.** A backup strategy that only copies files that have changed since the *last full backup*. To restore, you only need the last full backup and the most recent copy of this backup type. |  | 
| **2.** A leased facility that has power, HVAC, and raised floors, but contains no servers, network racks, or data. In a disaster, hardware must be procured and shipped here. |  | 
| **3.** A fundamental data protection topology stating you should have three total copies of your data, stored on two different types of media, with one copy kept off-site. |  | 
| **4.** A backup strategy that copies files that have changed since the *last backup of any kind*. To restore, you need the last full backup and every sequential copy of this backup type made since then. |  | 
| **5.** A fully operational alternate facility with duplicated hardware, live data replication, and network routing configured to failover in minutes if the primary site goes down. |  | 
| **6.** An instant point-in-time state of a virtual machine. Used as a quick safety net before applying software patches, but not considered a substitute for a true off-host backup. |  | 

### Section 2: Scenario-Based Multiple-Choice Questions (MCQs)

#### Question 1

An organization is conducting an annual exercise to determine which business functions are most critical, calculate the Maximum Tolerable Downtime (MTD) for each, and establish Recovery Time Objectives (RTO) and Recovery Point Objectives (RPO).

Which continuity planning document is the organization developing?

* A. Continuity of Operations (COOP)

* B. Business Impact Analysis (BIA)

* C. Acceptable Use Policy (AUP)

* D. Incident Response Plan (IRP)

#### Question 2

A systems administrator performs a Full backup on Sunday evening. On Monday, Tuesday, and Wednesday evenings, the administrator performs Incremental backups. On Thursday morning, the main database server suffers a catastrophic drive failure.

Which backup files are required to completely restore the server to its Wednesday evening state?

* A. Sunday Full + Wednesday Incremental

* B. Sunday Full + Monday, Tuesday, and Wednesday Incrementals

* C. Wednesday Incremental only

* D. Sunday Full + Thursday Incremental

#### Question 3

To ensure high availability for a popular web application, a cloud engineer deploys a cluster of five web servers. A specialized appliance sits in front of these servers, monitoring their CPU utilization and actively distributing incoming client HTTP requests to the server with the lowest current workload.

What technology is the engineer utilizing?

* A. Redundant Array of Independent Disks (RAID)

* B. Reverse proxy clustering

* C. Active/Passive failover

* D. Load balancing

#### Question 4

A government agency is planning for a catastrophic regional disaster (such as an earthquake or prolonged power grid failure). They develop a comprehensive plan that details how to relocate key personnel, leadership, and mission-essential functions to a secure alternate facility in a different state to sustain operations for up to 30 days.

Which of the following terms best describes this plan?

* A. Disaster Recovery Plan (DRP)

* B. Business Impact Analysis (BIA)

* C. Continuity of Operations (COOP)

* D. IT System Failover Plan

#### Question 5

A mid-sized company leases a secondary facility to use in case their primary data center is destroyed. The secondary facility has server racks, power, and active network connections. However, servers are not powered on, and backups are only delivered manually via tape once a week. The estimated time to bring this site online is 48 to 72 hours.

How should this secondary facility be classified?

* A. Cold site

* B. Warm site

* C. Hot site

* D. Mobile site

#### Question 6

A datacenter is equipped with massive diesel generators to provide redundant power in the event of a municipal grid failure. However, when the city grid drops, it takes approximately 15 seconds for the generators to start up and stabilize the voltage.

Which high availability component must be implemented to keep the servers running during this 15-second gap?

* A. Power Distribution Unit (PDU)

* B. Uninterruptible Power Supply (UPS)

* C. Dual power supplies

* D. Line conditioner

#### Question 7

A company implements a 3-2-1 backup strategy to protect against ransomware. They have the original production data (Copy 1), an on-premises NAS containing the nightly backups (Copy 2), and a third copy.

To strictly adhere to the 3-2-1 topology, where must the third copy reside?

* A. On a separate partition on the primary database server.

* B. On an external hard drive sitting on top of the on-premises NAS.

* C. Off-site, such as in an immutable cloud storage bucket or a physical vault in a different geographic region.

* D. On a flash drive carried by the IT director.

#### Question 8

An IT department performs a Full backup on Sunday. On Monday, Tuesday, and Wednesday, they perform Differential backups. If the server crashes on Thursday morning, which of the following is true regarding the restoration process?

* A. Restoration will be faster than if they had used Incremental backups, because they only need the Sunday Full and the Wednesday Differential tapes.

* B. Restoration will be slower than if they had used Incremental backups, because they must restore Sunday, Monday, Tuesday, and Wednesday sequentially.

* C. The Wednesday Differential backup will be exactly the same file size as the Monday Differential backup.

* D. They cannot restore the data without also having Thursday's backup.
