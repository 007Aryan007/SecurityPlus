#### Question 1
A security analyst discovers that an attacker was able to generate two different input files that produce the exact same SHA-1 cryptographic hash value. As a result, the attacker substituted a legitimate contract with a fraudulent version.

Which cryptographic vulnerability was exploited?

* A. Downgrade attack
* B. Collision
* C. Salt exhaustion
* D. Replay attack

#### Question 4
A network administrator observes that TLS connection establishment to an internal enterprise web server is slow due to clients making separate lookups to external CA servers to check whether the web server's certificate has been revoked. Which technology should the administrator configure on the web server to resolve both issues?

* A. OCSP Stapling
* B. Key Escrow
* C. Certificate Revocation List (CRL) distribution points
* D. Certificate Pinning

#### Question 5

Which technique is the auditor describing?

* B. Tokenization
* C. Steganography
* D. Hashing with a static salt

#### Question 6
