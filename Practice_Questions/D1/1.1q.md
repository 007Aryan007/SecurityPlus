#### PBQ 1: Control Matrix Classification

**Scenario:**
An enterprise is conducting a comprehensive internal audit across its cloud and on-premises environments. You are tasked with populating the security control register.

Match each implemented control below with its primary **Category** and its primary **Functional Control Type**.

**Controls to Classify:**

1. A corporate policy requiring all employees to renew NDA and Acceptable Use Policy (AUP) acknowledgments annually.

2. A mantrap (access control vestibule) installed at the entrance of a Tier III datacenter.

3. Conducting scheduled bi-weekly user access reviews by departmental managers.

4. An automated rule on a Next-Generation Firewall (NGFW) that inspects outbound traffic and drops connections destined for known C2 (command-and-control) IP addresses.

5. High-visibility warning signs posted along the perimeter fence stating: *"Armed Security On Site – Violators Will Be Prosecuted."*

6. Restoring a compromised SQL database server to a clean state from an immutable offline snapshot following a ransomware outbreak.

7. Requiring developers to use a temporary read-only sandbox environment with synthetic data because legacy architectural limitations prevent masking production data in test builds.

8. Daily automated audit log parsing that flags concurrent VPN logins originating from geographically impossible distances.

**Categories:**

* Technical

* Managerial / Administrative

* Operational

* Physical

**Functional Control Types:**

* Preventive

* Deterrent

* Detective

* Corrective

* Compensating

* Directive

### Section 2: Scenario-Based Multiple-Choice Questions (MCQs)

#### Question 1

A financial institution wants to reduce the likelihood of unauthorized transactions executed by rogue system administrators. The Chief Information Security Officer (CISO) mandates that any ledger adjustment exceeding \$50,000 requires the cryptographic authorization of two separate administrators, and no single administrator may approve their own transaction.

Which of the following best describes this control mechanism?

* A. A detective technical control

* B. A preventive managerial control

* C. A compensating operational control

* D. A directive physical control

#### Question 2

Following a series of unauthorized after-hours break-ins at a corporate warehouse, the facility manager installs motion-activated floodlights, highly visible surveillance camera housings, and warning banners along the property line.

Which control type do these specific measures primarily represent?

* A. Deterrent

* B. Corrective

* C. Directive

* D. Compensating

#### Question 3

An organization’s cloud environment utilizes an Amazon GuardDuty service that continuously analyzes VPC flow logs, DNS logs, and CloudTrail events. When anomalous credential behavior is observed, an alert is pushed to the Security Operations Center (SOC) dashboard for triage.

How should this control be classified?

* A. Operational and Preventive

* B. Technical and Detective

* C. Managerial and Directive

* D. Technical and Corrective

#### Question 4

A legacy healthcare application cannot natively support multi-factor authentication (MFA) or modern cipher suites. Upgrading the application software is currently cost-prohibitive. To mitigate this vulnerability while maintaining compliance, security engineers deploy a reverse proxy in front of the application that enforces MFA, TLS 1.3 termination, and IP-based geofencing before forwarding requests.

Which control type does the reverse proxy implementation represent in this scenario?

* A. Compensating

* B. Directive

* C. Corrective

* D. Deterrent

#### Question 5

During an annual internal compliance audit, an auditor discovers that the security team conducts monthly manual reviews of server termination scripts, executes scheduled user offboarding checklists, and regularly inspects physical visitor sign-in logs.

Under which control category do these ongoing operational day-to-day practices fall?

* A. Managerial

* B. Operational

* C. Technical

* D. Physical

#### Question 6

An incident response team is responding to a zero-day exploit on a critical Linux web server. The responders isolate the virtual machine, kill the malicious processes, apply an emergency software patch provided by the vendor, and re-image the operating system partition.

The actions taken by the incident response team are examples of which control type?

* A. Preventive

* B. Detective

* C. Corrective

* D. Compensating

#### Question 7

A company updates its employee handbook to include a mandatory clean desk policy, explicit guidance on acceptable remote work behaviors, and strict disciplinary actions for sharing multi-factor authentication codes.

Which control type is exemplified by the language and policies contained in the handbook?

* A. Directive

* B. Deterrent

* C. Detective

* D. Preventive

#### Question 8

A manufacturing plant installs bollards at the perimeter of the corporate campus, heavy motorized security gates at vehicle checkpoints, and biometric retinal scanners on all entrances leading to industrial control system (ICS) server rooms.

Which of the following statements is true regarding these controls?

* A. The bollards and biometric scanners are both categorized as physical preventive controls.

* B. The bollards are physical preventive controls, while the retinal scanners are purely technical detective controls.

* C. The gates and bollards are compensating physical controls, while the retinal scanners are operational directive controls.

* D. All three implementations are categorized as managerial deterrent controls.
