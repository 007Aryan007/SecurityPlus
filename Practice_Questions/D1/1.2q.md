**Task 1: Control Plane vs. Data Plane Mapping**
Classify each operational action below into either the **Control Plane** or the **Data Plane**:

1. A Policy Enforcement Point (PEP) inspects TLS-encrypted HTTP headers and forwards authorized API traffic to the backend database.

2. A Policy Engine (PE) evaluates device compliance state, user risk score from the IdP, and current geo-velocity to determine access authorization.

3. A Policy Administrator (PA) issues a short-lived x509 credential and dynamic firewall rule allowing a client to reach a resource.

4. An endpoint agent streams bulk application telemetry and encapsulated packet data directly to a cloud proxy.

  3. An intentionally unpatched, isolated Windows Server 2016 VM listening on port 445 (SMB) within an isolated DMZ subnet.

### Section 2: Scenario-Based Multiple-Choice Questions (MCQs)

#### Question 1

A software engineering team implements an automated release pipeline. As part of their artifact verification, each compiled binary is signed using the lead build engineer's private key via an internal Hardware Security Module (HSM). When the deployment server receives the binary, it verifies the signature using the corresponding public certificate.

Which of the following fundamental security properties is primarily ensured by this implementation?

* A. Microsegmentation and availability

* B. Integrity and non-repudiation

* C. Data plane isolation and confidentiality

* D. Authorization and fault tolerance

#### Question 2

An enterprise network currently allows any device connected to the internal corporate LAN to query internal DNS servers, connect to file shares, and browse internal intranet portals without re-authenticating, as long as the device is physically located inside the office headquarters.

Under a Zero Trust Architecture (ZTA) framework, which fundamental design flaw does this environment exhibit?

* A. Out-of-band control plane routing

* B. Implicit trust zones

* C. Absence of honeytokens

* D. Decoupled policy enforcement

#### Question 3

A security engineer places an unadvertised fake database record containing mock patient credit card details into a production customer database. The engineer then configures SIEM alerts to notify the on-call incident response team immediately if this specific record is ever returned in a `SELECT` query.

Which deception technique is being utilized in this scenario?

* A. Honeypot

* B. Honeytoken

* C. Honeynet

* D. Honeyfile

#### Question 4

An employee logs into a corporate workstation by providing a username and a FIDO2 WebAuthn hardware security key. Once authenticated, the identity provider evaluates the employee's group memberships and issues a SAML assertion with specific claims granting read-only access to the billing portal. All actions performed within the billing portal are written to a centralized, append-only syslog repository.

Which component of the AAA framework is represented specifically by the SAML assertion granting read-only access?

* A. Authentication

* B. Authorization

* C. Accounting

* D. Non-repudiation

#### Question 5

A financial trading platform implements distributed microservices running on a Kubernetes cluster. To prevent lateral movement in the event that a public-facing web microservice is compromised, the security team implements granular ingress and egress network security policies so that each container pod can only communicate with the specific downstream database pod it requires.

Which concept does this deployment best exemplify?

* A. Honeytoken deployment

* B. Microsegmentation

* C. Control plane redirection

* D. Geographic redundancy

#### Question 6

During an architecture review of a Zero Trust implementation based on NIST SP 800-207, an auditor notes:

> *"The component responsible for making the ultimate decision to grant, deny, or revoke access to a resource operates separately from the mechanism that intercepts and terminates the actual network connection."*

Which pair of Zero Trust components is the auditor referring to?

* A. Policy Engine (PE) and Policy Enforcement Point (PEP)

* B. Data Plane and Honeynet

* C. Policy Administrator (PA) and Certificate Authority (CA)

* D. Implicit Trust Zone and Security Information and Event Management (SIEM)

#### Question 7

An attacker compromises a web application server and modifies existing records in a critical inventory database without triggering any error logs. Customers receive shipments of the wrong items, but the system continues to run without experiencing any downtime or unauthorized disclosure of personal identifiable information (PII).

Which pillar of the CIA Triad has been directly violated?

* A. Confidentiality

* B. Integrity

* C. Availability

* D. Non-repudiation

#### Question 8

A cybersecurity team sets up a virtual machine configured to look like a vulnerable, internet-facing Apache web server running an outdated version of Struts. The system contains synthetic customer records and mock transaction logs, but possesses no production value. The team uses it exclusively to observe adversary tactics, techniques, and procedures (TTPs) in real time.

Which of the following best classifies this deployment?

* A. Honeytoken

* B. Honeypot

* C. Policy Enforcement Point

* D. Compensating control plane
